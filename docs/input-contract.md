# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

deliveries为投递明细，row稳定，仅用于独立核对；person是同口径居民身份，可跨站日重复。重量吨数精确三位，金额为CNY分。单价是金额总和除重量总和，不对行均价或日均价再平均。零分母无定义，未知分母与零分母不得混同。
site_day支持站点/日粒度的weight_sum、amount_sum及单日单站person_count，city_day支持整市/日；两者均没有居民身份集合，不能合并其person_count得到跨站跨日独立人数。均不支持按material过滤或分组。stock是站日库存状态，日历末日必须有完整同口径状态方可回答期末；库存不相加多个日期。
inputs/coverage.json是输入汇总文件的完整覆盖声明；声明区间内零行是空覆盖，未声明日期不可视为空。inputs/queries.json列出实际请求（范围、维度、指标、map_version和detail_row_budget）；预算仅计执行时从deliveries打开读取的行数，不能预读全表后藏在缓存。map_version选择用哪版site_map解释站点区域，旧汇总带自己的版本，不能重贴标签。明细可以按所选映射重关联。
为进行业务核对，允许单独的无预算明细路径；不可把它的结果缓存用作受限请求的答案。没有近似独立人数授权。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。
